# Ilford Muslim Welfare Association

The official website for Ilford Muslim Welfare Association, a mosque and community centre serving families and young people in Ilford.

**Live website:** [ilfordmasjid.co.uk](https://www.ilfordmasjid.co.uk/)

## Features

- Mobile-first responsive design
- Live prayer times through Masjidbox
- Youth club and madrasa information
- Services, gallery and donation pages
- WhatsApp community links and contact details
- Search and social sharing metadata

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Custom CSS
- Vercel Analytics
- Vercel hosting

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Create a production build with:

```bash
pnpm build
```
